# RELAY design

RELAY is a focused studio utility. The current direction takes the orderly rows,
flat charcoal surfaces and clear primary action of Audiomovers as a craft reference.
The RELAY mark, Barlow typography, Studio Blue accent and stereo signal display
remain its own identity. Do not reproduce Audiomovers assets or screen compositions.

## Plugin

A 680 × 440 logical canvas: 64px header, flexible body, 56px footer.
The adapter preserves aspect ratio for proportional host resizing; minimum bounds
are 600 × 389. Host acceptance and monitor DPI need verification in a DAW.
Repeated controls use 40px rows, a 64px label gutter and 32px controls. Numeric
readouts have fixed widths. Flexible text and control containers may shrink.
The compact spectrum has a 120px ceiling; stereo meters occupy an 80px lane.
Settings stay in the existing popover. Share, Join and parameter behavior are preserved.

## Palette and type

Dark ground #18181a, editor #202022, controls #29292c, dividers #39393e.
White text, #b8b8b8 secondary text, #00aaff primary actions and focus.
Green, amber and red communicate signal and connection state. Retain light mode.
Barlow throughout; 12–13px plugin labels, 18px session field. Corners 2–4px.

## Web

The product page uses a 1200px maximum width, large responsive heading and a
real editor capture. Two columns become one below 860px. Specifications form
one divided strip rather than independent cards.
The listener remains a focused task surface: a 480px unboxed join form, clear
session field and Listen action. Live signal history is shortened to keep volume
and meters accessible. Preserve native keyboard controls, visible focus, touch
sizes, connection states, passwords and diagnostics.
